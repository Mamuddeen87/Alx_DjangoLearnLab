# Django Admin Configuration for Book Model

## Model Registration
The Book model was registered with the Django admin interface to enable administrative management.

## Admin Customization
The admin interface was customized using a ModelAdmin class to:
- Display title, author, and publication_year in the list view
- Enable filtering by author and publication year
- Allow searching by title and author

## Outcome
The Django admin interface provides an efficient and user-friendly way to manage Book records.
